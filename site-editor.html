接続キーを作成 ↗

このChromeに接続キーが暗号化保存されています。

接続キーはGitHubだけに送信します。このチャットや掲載本文には貼り付けないでください。

初回設定の手順
  1. 「接続キーを作成」を開き、GitHubにログインします。
  2. Repository access → Only select repositories を選び、hayashi-naika-website だけを指定します。
  3. Repository permissions の Contents → Read and write を確認します。その他の追加権限は不要です。
  4. Generate token で発行されたキーを上の欄に貼り、接続します。

作成画面の有効期限は90日を初期指定しています。期限切れ・失効時は新しいキーに差し替えてください。暗号化保存を選ぶと、次回から解除用パスワードで接続できます。パスワードはGitHubのログインパスワードとは別にしてください。

接続中のキーはメモリー内だけで使用します。操作のない状態が30分続くと接続を解除します。暗号化保存も共有端末・不審な拡張機能のある端末では使用しないでください。

移転時の優先事項

  1. 既存の医院プロフィールを更新し、同じ医院の重複登録を避ける。
  2. 臨時休診日は「特別営業時間」に登録。10月30日・31日の休診も確認する。
  3. 新医院の外観・入口・駐車場の実写真を追加する。
  4. 小松市民病院のかかりつけ医一覧、医師会などの掲載先へ移転後の住所と公式サイトURLの更新を依頼する。2026年10月24日の確認では、市民病院の掲載住所はホ103、HP欄は空欄でした。
