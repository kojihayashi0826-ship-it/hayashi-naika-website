# 林内科医院ウェブサイト — 最初に読むファイル

このフォルダは **GitHub Pages用** です。`index.html` が見える階層のファイルを、現在のGitHubリポジトリへ置き換えてください。

## 今回の追加内容

- 「予約なしでも受診できます」の枠内にデジスマ予約ボタンを追加
- 上部メニューの「よくある質問」の右に「スタッフ募集中」を追加
- 「お知らせ・流行状況」の下にスタッフ募集欄を追加
- 予約案内・スタッフ募集を `site-editor.html` で編集可能
- 表示・非表示、募集条件の追加・削除・並び替えに対応

## 重要

デジスマの医院専用予約URLが元データに入っていなかったため、予約ボタンは初期状態では非表示です。
`site-editor.html` でURLを入力し、「表示する」を選んで `site-updates.json` を作成してください。

詳しい更新手順は `GITHUB_UPDATE_GUIDE.md` を参照してください。
