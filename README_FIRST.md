# 林内科医院ウェブサイト — 最初に読むファイル

このフォルダは **GitHub Pages用** です。`index.html` が見える階層のファイルを、現在のGitHubリポジトリへ置き換えてください。

## 今回の主な変更

- デジスマ等の予約システム表示を完全に削除
- 通常診療は受付時間内に直接受診できる旨へ変更
- 「正式公開前・ウェブサイト調整中」の案内を追加
- Chromeで動く `site-editor.html` を「サイト更新アプリ」に刷新
- お知らせ・流行情報・重要案内・臨時休診・スタッフ募集をGUIで編集可能
- フルミストのお知らせ案を、公開されない下書きとして登録
- タイトル、説明文、構造化データ、サイトマップ、アイコン等のSEO基盤を改善

## 更新アプリ

公開後は次のURLから開けます。

`https://www.hayashinaika.clinic/site-editor.html`

編集後に `site-updates.json` を作成し、GitHubの `data/site-updates.json` と置き換えてください。Chromeでは、展開済みサイトフォルダへ直接保存することもできます。

詳しい手順は `GITHUB_UPDATE_GUIDE.md` を参照してください。
